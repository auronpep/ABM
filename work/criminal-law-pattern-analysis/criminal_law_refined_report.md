This means 165 of 181 critical items, or about 91 percent, have at least a partial answer-choice axis signal.

The product insight is not "ignore the stem." It is:

1. Read choices first to name the menu.
2. Predict the legal axis.
3. Read the stem only for the breaker fact.
4. Refuse the morally attractive answer unless it satisfies the axis.

## Refined BarMatrix Modules

### 1. Answer Menu Decoder

Purpose:
Train students to classify answer choices before reading deeply.

Core move:
Ask, "What menu are these choices giving me?"

Menu labels:

- charge ladder
- property label switchboard
- right source
- remedy result
- search threshold
- yes/no because
- combination grid

Representative IDs:
21601, 20881, 14698, 18132, 19299, 20700, 20938.

### 2. Breaker Fact Finder

Purpose:
Train students to read the stem for only the fact that resolves the menu.

Core move:
After naming the menu, ask, "What one fact breaks the tie?"

Breaker labels:

- trigger/attachment
- missing element
- mens rea
- timing/status
- remedy/prejudice
- scope/identity
- burden/proof
- exception precondition

Representative IDs:
18132, 21638, 21156, 21718, 20112, 18296.

### 3. Right Source Switchboard

Purpose:
Fix Criminal Procedure overgeneralization.

Core move:
Before applying a right, name the source and trigger.

Student-facing line:
"Lawyer facts are not all the same right."

Tensions:

- Miranda/Fifth counsel vs Sixth counsel
- custody/interrogation vs formal charge
- offense-specific Sixth Amendment vs broader Miranda invocation
- photo array vs corporeal confrontation
- critical stage vs ordinary police investigation

Representative IDs:
20881, 18132, 17244, 17196, 18598, 20427.

### 4. Remedy Ladder

Purpose:
Stop students from converting every violation into suppression or reversal.

Core move:
Separate wrong, remedy, and review standard.

Student-facing line:
"A violation is not yet an answer."

Tensions:

- Miranda statement vs physical fruit
- Brady nondisclosure vs material suppression
- constitutional error vs harmless error
- misconduct vs prejudice
- habeas/appeal gatekeeping

Representative IDs:
18308, 20816, 14558, 17589, 19743, 20971.

### 5. Property Crime Switchboard

Purpose:
Turn property crimes into a small set of axis questions.

Core move:
Ask what moved: possession, title, custody, force, or legal significance.

Student-facing line:
"Fraud is not the label. What did the victim transfer?"

Tensions:

- larceny by trick vs false pretenses
- larceny vs embezzlement
- robbery vs larceny
- forgery vs false document with no legal effect
- arson burning vs smoke/heat
- receiving stolen property status at receipt

Representative IDs:
19299, 21156, 21105, 19080, 20122, 18156, 20689, 14711.

### 6. Homicide and Mens Rea Ladder

Purpose:
Stop emotional grading of homicide.

Core move:
Do not ask "how bad was it?" Ask which mental state and mitigation facts are present.

Student-facing line:
"Intent to kill is not the whole homicide chart."

Tensions:

- murder vs voluntary manslaughter
- voluntary vs involuntary manslaughter
- imperfect self-defense
- depraved-heart murder
- felony murder
- malice vs specific intent

Representative IDs:
20700, 19008, 14657, 17052, 21718, 16054, 21526.

### 7. Scope, Merger, Identity

Purpose:
Fix same-story overreach.

Core move:
Ask whether the law treats the events as the same offense, a separate offense, or a merged offense.

Student-facing line:
"Same story is not the same offense."

Tensions:

- conspiracy does not merge
- attempt merges into completed offense
- withdrawal does not erase completed conspiracy
- Blockburger element identity
- Sixth Amendment offense-specific rule

Representative IDs:
18101, 20938, 19934, 20112, 21412, 17196.

### 8. Combination Grid

Purpose:
Handle both/neither/proposal A/proposal B questions.

Core move:
Build a two-axis table before choosing.

Student-facing line:
"Do not average the propositions. Test each box."

Representative IDs:
14619, 14596, 19651, 19357, 21011, 19484, 20789.

## Refined Student Algorithm

1. Read the call.
2. Read answer choices.
3. Name the answer menu.
4. Predict the legal axis.
5. Read the stem for the breaker fact.
6. Reject moral gravity.
7. Match the answer to the axis, not the story.

For Criminal Law/Procedure, the highest-yield menus are:

- rights source menu
- remedy result menu
- property crime label menu
- homicide ladder menu
- inchoate/scope menu
- combination grid
